# ADR-0001: Stack technologiczny (stan: październik 2026)

- **Status:** zaakceptowany (2026-10-07)
- **Kontekst:** audyt `docs/AUDIT.md` §2.2; projekt ma być w 100% na darmowych planach i zgodny z dobrymi praktykami drugiej połowy 2026 r.

## Decyzja

| Warstwa | Wybór | Wersja (2026-10-07) |
|---|---|---|
| UI | React | 19.3 |
| Język | TypeScript (strict) | 5.9 |
| Build | Vite (Rolldown) | 8.3 |
| Style | Tailwind CSS | 4.3 |
| Stan | Zustand | 5.0 |
| Animacje | `motion` (dawniej `framer-motion`) | 14.0 |
| Drag & drop | dnd-kit | 6.3 / 10.0 |

| Testy | Vitest + jsdom (+ Testing Library dla komponentów) | 5.0 |
| Lint / format | ESLint (flat) + Prettier | 10.x / 3.x |
| Hosting | Vercel Hobby + GitHub Actions (public repo) | — |

## Konsekwencje

- `framer-motion` zastąpiony pakietem `motion` (importy `motion/react`) — twórca zmienił nazwę; `framer-motion` pozostaje aliasem, ale nowy pakiet jestprimary.
- Vite 8 używa Rolldown — konfiguracja chunków przez `advancedChunks` (obiektowy `manualChunks` już niedostępny); build ~6× szybszy.
- Aktualizacje major robimy w osobnych PR-ach z pełnym weryfikacją (lint/typecheck/test/build).
- Wszystko darmowe: Vercel Hobby (non-profit, 1 seat), Supabase Free, GitHub Free (publiczne repo z nieograniczonymi minutami Actions).

## Odrzucone alternatywy

- **Next.js/Remix** — aplikacja jest czysto kliencka (SPA + PWA), SSR nie daje korzyści, a komplikuje hosting darmowy.
- **Biome zamiast ESLint+Prettier** — szybszy, ale mniejszy ekosystem reguł (react-hooks); zostajemy przy sprawdzonym zestawie (rewizja przy najbliższej majorce).
